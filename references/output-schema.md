# Output Schema

`report.json` is the source of truth for single-paper analysis.

## Single-Paper Keys

- `paper_metadata`
- `research_problem`
- `core_idea`
- `method`
- `experimental_setup`
- `datasets`
- `baselines`
- `metrics`
- `results`
- `comparison_table`
- `limitations`
- `applicability`
- `reproducibility`
- `significance`
- `credibility_assessment`
- `uncertainties`

## Comparison Keys

- `papers`
- `shared_task`
- `method_comparison`
- `experiment_comparison`
- `metric_alignment`
- `baseline_alignment`
- `strengths_and_weaknesses`
- `research_gaps`
- `overall_takeaways`

Use explicit placeholders such as `unknown` or `not_reported` instead of guessing.
